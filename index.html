    4roll-0.4좌우 기울기 (°)

    7pwm3출력 0~255 (D면 스로틀, B면 제동 세기)
    8stateBD 스로틀 / C 출력 끊음 / B 제동
    9yaw0.1회전 각속도 (°/s), 오른쪽 +

    state

    • B 목표보다 0.03 m/s 넘게 빠름. 제동 PWM = 600 × 초과 속도 + 쌓인 값, 20ms에 최대 25씩 증가
    • C 목표 ±0.03 안. 쌓인 제동이 남아 있으면 B 유지
    • D 목표보다 느림. 스로틀 190

    글자 색

    • 초록 차에서 온 줄
    • 파랑 보낸 명령
    • 회색 앱 메시지

    명령

    • s 경사로 주행 (부저 3번 뒤 출발)
    • x 정지
    • c 자이로 영점 (평평한 곳에 두고)
    • i IMU 점검
    • l r 왼쪽 / 오른쪽 바퀴만 2초 (바퀴 띄우고)
    • ? 상태, 명령 목록
    • t 회전 주행 (시뮬레이션은 03 회전 코스 화면)
    • f 직진 주행 (시뮬레이션은 04 전도 상황 화면)

    주행 끝

    멈춘 이유 한 줄(주행 거리 도달 1.6 m, 주행 시간 초과 8초, 수동 정지, 기울기 초과로 정지)과 요약 한 줄(코스, 모드, 최고 속도, 주행 거리, 회전각, IMU 버린 샘플 수).

    prj_test3.ino 기준. 시뮬레이션 값은 계산값 (실측 아님).
